# 原始传感器驱动的动态浮标—UAV相干发射仿真

本目录独立扩展当前IMM/CI实验，原实验与归档不覆盖。补齐的是物理运动→原始传感器→导航解算→UAV跟踪→未来双方运动→实际复场的可执行链路，不声称已得到全局最优联合后验或最高期望相干增益。

运行完整批次：

```powershell
cd D:\git\sim2
python -u kf_dpc_coherent_5nodes/raw_sensor_maritime/run_full.py --trials 20
python kf_dpc_coherent_5nodes/raw_sensor_maritime/report.py
```

默认输出仅本目录outputs，重跑会覆盖本目录同名结果。本任务不运行冒烟测试、门限测试或缩短版实验。完整实验全部0–90s、20种子、2种波高、5条UAV轨迹和4种方法均保留。

## 物理和传感器

- 20浮标仍以100m圆环初始布放，高度基线1.5m。
- 慢漂移是均值海流[0.3,0.1,0]m/s叠加80/120/180s随机低频速度分量，解析积分得到中心位置。它是有限谱有色过程，不声称是精确OU样本。
- 快运动为共享方向JONSWAP有限谱波场，Hs=0.5/1.5m，Tp=6s；有限水深50m。平移和姿态使用明确的简化复数响应，位置、速度、加速度和角速度来自同一条连续轨道。
- 从归档maritime.py复用谱归一化、有限水深色散、复响应和刚体运动数学，没有加载归档导航输出模拟器或旧实验入口。
- GNSS传感器输出8个伪距：距离＋漂移接收机钟差＋独立测距误差；已知合成卫星位置，0.30m测距标准差。视为经过差分/改正的码测距理想化；未模拟载波模糊度、卫星钟、对流层、电离层、多径或信号捕获，不称完整GNSS射频仿真。
- IMU 50Hz：比力和机体系角速度，有初始偏置、随机游走和白噪声。每个包在区间末可用，用中点真值近似该区间平均；非直接导航状态。
- 磁强计5Hz：已知局部地磁向量的机体系观测，有测量噪声，无磁干扰。用于提供独立航向参考。
- 雷达5Hz：原始距离、方位、俯仰；无Doppler输入。
- GNSS/IMU/雷达/发射相位中心共位，杆臂全部为零。每浮标一个各向同性等效阵元，真实姿态仍影响雷达与IMU观测。不同于旧实验每浮标2×2子阵，不作混淆比较。
- 总发射功率固定1W；RF载频与相位同步理想，仍未模拟同步协议。300MHz/1GHz。

## 算法边界

1. InertialNavigation只接收pseudoranges/gyro/accel/mag。初始位置和钟差由伪距非线性最小二乘解算；初始姿态由首个比力和磁场观测确定；初速度和偏置均置零并给不确定度。无真值初始化。
2. 16维右误差ESKF估计位置、速度、姿态、加速度偏置、陀螺偏置和钟差。50Hz惯性递推、5Hz伪距和地磁更新。
3. UAV采用原始雷达球坐标的CV或S/CV/CT IMM-EKF。测量协方差加入导航位姿完整边际协方差传播，而不是把真实浮标位姿作为已知输入。
4. UAV后验经25轮固定环网DPC或CI；CI无信息N倍放大、无真值权重、无门控，不回灌本地IMM。
5. 浮标线性预测来自估计位置/速度；波浪预测由因果二时间尺度滤波拟合导航位置/速度，不读取真实中心和真实波浪。窗口之外未来随机相位不传给算法。
6. 目标与浮标均预测到137–177ms后的实际时隙，逐时刻算精确几何距离命令，不把曲线平滑结果冒充未来预测。
7. 通道评价才接收未来真值距离，计算实际复场；ideal仅作评价上界，无真值相位命令进入算法。

## 方法对照

|方法|UAV模型|融合|浮标预测|
|---|---|---|---|
|CV_CI_wave|CV|CI|估计的波浪模型|
|IMM_DPC_linear|S/CV/CT IMM|DPC|估计位置速度直线外推|
|IMM_CI_linear|S/CV/CT IMM|CI|估计位置速度直线外推|
|IMM_CI_wave|S/CV/CT IMM|CI|估计的波浪模型|

在每海况/种子内共用全部原始导航和雷达随机数，五种轨迹为悬停、直线、圆周、混合机动和直线爬升。同样发射时刻用于所有方法；硬件算力、消息载荷和带宽开销未实测。

## 可信度与已知近似

输出位置/速度RMSE、未来位置RMSE、差分路径误差、实际相干效率、NEES和名义95%区域经验覆盖率。覆盖率只描述误差与协方差是否匹配，不筛选任何数据。时间和节点误差相关，不能把逐帧样本当成独立显著性样本。

这一版为分层导航/跟踪，尚非UAV与全部浮标的完整联合MAP：雷达递推近似忽略先验UAV误差与当前导航误差的交叉相关；波浪拟合重用时间相关的导航后验，输出协方差不作为已校准联合置信度。CI输入也是近似协方差，不宣称CI自动保证实际可信。结果不好时原样保留，不根据真值调参或剔除机动。

## 文件

- physics.py：仅仿真器使用，运动真值和原始观测。
- estimation.py：传感器驱动的浮标导航、因果波浪分解预测。
- target.py：原始雷达CV/IMM更新。
- run_full.py：完整配对实验及评价；真值与传感器文件分开保存。
- report.py：完整数据汇总与绘图，不重跑实验。
- THEORY.md：具体数学推导、假设和正式出版文献。
- RESULTS.md：正式完整批次生成后才产生。

首种子的sensor/radar文件是算法输入；truth_*文件仅作离线评价。manifest记录种子、参数、依赖版本及源文件SHA256；progress记录40个海况/种子case的进度。

执行记录：第一次完整启动在混合轨迹处因新配置缺少frame_budget_s而停止，日志保留为outputs/initial_incomplete_run.log。补齐该配置后从第一个种子重新运行完整批次；正式CSV和manifest只包含这次完整运行，不拼接失败进程的部分数据。
